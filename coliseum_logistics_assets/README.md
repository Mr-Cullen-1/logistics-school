# Coliseum Logistics School — Design Assets Pack

## Included
- `brand/`: original SVG logo concepts (horizontal, stacked, mark, light variant)
- `icons/`: 23 individual editable SVG outline icons
- `images/photography/`: concept image crops from the generated brand board
- `images/backgrounds/`: dark logistics background texture
- `tokens/`: JSON and CSS design tokens
- `ui/`: reusable button styles
- `images/brand-board-preview.jpg`: full board preview

## Brand tokens
- Charcoal: `#0D1114`
- Dark Slate: `#161B1F`
- Bronze: `#B8814A`
- Gold: `#D4AF7C`
- Ivory: `#F4F1E8`
- Gray 100: `#A7A7A7`
- Gray 200: `#6B7280`
- Optional alert red: `#E15757`

## Notes
- SVG logos and icons are editable vector assets.
- The photo/background files are concept crops from the generated design board, not original camera photography or clean standalone renders. Use them as visual placeholders or references; replace with approved original photography before production.
- Any sample metrics visible in the board (e.g. students trained or success rate) are illustrative only and must not be published unless verified.
- The logo is a fresh vector concept based on the board direction and should be reviewed before final brand approval.
- Suggested font: Inter. Load the font separately if you need consistent rendering across environments.
